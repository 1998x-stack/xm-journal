# Source study and design transfer

| Source | Transferable method | Do not copy |
|---|---|---|
| [Christopher Olah — Understanding LSTM Networks](https://colah.github.io/posts/2015-08-Understanding-LSTMs/) | Starts with a familiar question, introduces a visual vocabulary, and progressively opens a complex mechanism | Article prose, GIFs, diagrams, branding or HTML |
| [Harvard NLP — The Annotated Transformer](https://nlp.seas.harvard.edu/annotated-transformer/) | Explains a system in dependency order, pairs each step with a concrete example, and makes implementation details inspectable | Notebook source, long code excerpts or figures without permission |
| [Olah-style-posts](https://github.com/1998x-stack/Olah-style-posts) | Reusable semantic HTML, responsive article CSS, SVG production, small interactions, validation and browser QA | Unreviewed wholesale changes that would erase journal-specific requirements |

## Adaptation for a personal journal

A research article explains a technical object. A journal article explains a lived day and the user's evolving mental model. The transferable core is progressive disclosure: concrete moment first, abstraction later, one explanatory figure per question.

The visual identity must be independently composed for each entry. Do not reuse a generic cover or turn every personal reflection into the same diagram.
